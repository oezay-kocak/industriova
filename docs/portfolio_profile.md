## Portfolio description — English

Industriova is a personal industrial simulation and portfolio project that turns interconnected production, energy, storage, logistics and progression requirements into a working Python/PySide6 desktop application.

I conceived the product, designed its gameplay loop, domain architecture and features, and planned and directed implementation by AI agents. I reviewed the results against the intended rules and used tests and playtest observations to guide revisions. I did not personally write the implementation code; AI agents carried out the programming. My contribution is product conception, requirements analysis, system design, development direction and review of results.

The project includes the application, a case study, economic analyses and documented QA evidence. It provides an inspectable example of translating requirements into executable rules, investigating inconsistencies and validating AI-assisted work, with the limits of the available evidence stated explicitly.
